# 小说版开发范围

用户条件 → 远端搜索 / 本地规则 → Rust 获取分页 → ID 去重 → 本地筛选排序 → 按需读取正文。

不预建作品库，不需要手动维护数据。后续只做有容量和有效期的自动缓存。

## 模块

| 目录                    | 职责                                    |
| ----------------------- | --------------------------------------- |
| `src/domain`            | 独立作品类型；缺失统计保留为 null       |
| `src/features/search`   | 条件分配、去重、过滤与稳定排序          |
| `src/features/settings` | 登录界面、阅读偏好和默认搜索条件        |
| `src/features/reader`   | 受控正文文档、排版和高级 CSS            |
| `src/platform`          | 原生命令桥接和 Pixiv provider           |
| `src/providers`         | provider 契约和明确标识的虚构样例       |
| `src-tauri/src/pixiv`   | PKCE 登录、令牌刷新、安全存储和真实请求 |

## 当前行为

- 默认使用真实小说接口，登录后搜索。演示来源必须在设置中显式切换。
- 支持标签部分/完全匹配与关键词搜索；API 层也支持日期范围。默认按发布日期获取候选，本地按收藏数、浏览数和发布日期升降序排序，同值用日期作为第二排序条件。
- 标签完全匹配排除、标题/简介关键词排除、收藏/浏览/字数上下限。未知统计不满足数字筛选，排序放在末尾。
- 按需获取下一页，对累计作品去重并重新排序；本地条件调整不触发网络请求。
- 保存默认搜索条件；下次启动或搜索页“恢复默认”时使用。当前临时调整不会覆盖默认值。
- 登录凭据保存在系统安全存储，仅刷新令牌持久化。前端只获取账号 ID、名称与状态。退出删除本机凭据，账号切换清空搜索和阅读会话。
- 阅读偏好保存在本机。高级 CSS 位于无脚本、无应用权限的 sandbox 正文 iframe 中；外部资源禁用。支持章节、换行、分页和注音，插图暂显示占位。
- 新搜索和页面退出会丢弃旧响应；Rust 请求仍可能继续直到返回或 30 秒超时，尚未实现网络层取消。

排序仅覆盖已获取的作品。“无下一页”只表示 Pixiv 未给出下一页，不能解释为全站完整作品库；收藏数排序也不是官方人气算法。

## 后续验收

1. 真实账号完成登录、刷新恢复、退出、搜索分页和正文实测。
2. 搜索日期 UI、请求预算、重试、自动补页和真正取消。
3. 系列目录与前后篇、阅读位置恢复、插图与更完整的特殊标记。
4. 自动缓存和跨平台验证；Android / iOS 登录窗口及安全存储另行接入与验收。

本轮不做预建数据库、公共作品数据分发、正文全文搜索、图片/漫画浏览、下载管理或云同步。

## 校验

`npm run check`：搜索规则、偏好保存、正文标记与注入边界、类型和前端构建。
`cargo test --locked --manifest-path src-tauri/Cargo.toml --lib`：接口映射、正文解析、登录响应和可信地址限制。
